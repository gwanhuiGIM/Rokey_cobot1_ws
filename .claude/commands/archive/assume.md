# 가정 검수

지금 진행 중인 작업(또는 방금 작성한 코드/계획)에서 **네가 사용자에게 확인받지 않고 임의로 정한 것**을 전부 꺼내라.

## 규칙
- 사용자가 명시적으로 말한 것은 가정이 아니다. **네가 채워넣은 것만** 쓴다.
- "합리적이니까 괜찮다"고 스스로 판단해서 빠뜨리지 마라. 그런 것일수록 틀린다.
- **비용이 큰 순서**로 정렬하라. 틀렸을 때 되돌리는 비용이 큰 것이 위다.
- 최소 5개는 찾아라. 못 찾겠으면 아래를 훑어라: 좌표계·단위, 실행 환경, 하드웨어 개체차,
  동시성, 실패 시 동작, 데이터 분포, 성능 목표, 누가 이 코드를 유지보수하는가.

## 출력 형식
| # | 내가 가정한 것 | 틀렸을 때 손해 | 확인 방법 | O/X |
|---|---|---|---|---|
| 1 | 카메라와 로봇 베이스 사이 캘리브레이션이 최신이다 | 전체 좌표 오프셋, 재작업 반나절 | `ros2 run tf2_ros tf2_echo base camera_link` | |

표를 출력한 뒤 **멈춘다.** 사용자가 X를 찍은 항목만 다시 다룬다.
사용자가 X 표시하며 알려준 사실은 `docs/context/constraints.md`에 즉시 기록한다.
