# 실패 → 영구 규칙 승격

이것이 하네스 엔지니어링의 핵심 루프다: **에이전트가 실수했을 때 그 실수를 구조적으로 불가능하게 만든다.**

## 1) 이번 세션에서 잘못된 것을 모두 나열하라
$ARGUMENTS
(지정이 없으면 이 세션의 대화와 커밋을 스스로 훑어서 찾아라)

| # | 무엇이 잘못됐나 | 왜 그렇게 됐나 (근본 원인) | 사람이 몇 번 고쳐줬나 |
|---|---|---|---|

## 2) 각 항목을 아래 4가지 중 **가장 강한 수단**으로 승격하라
| 수단 | 강도 | 언제 쓰나 |
|---|---|---|
| CLAUDE.md 규칙 1줄 | 약 | 판단이 필요한 관례 |
| `.claude/settings.json` deny/hook | 강 | 절대 하면 안 되는 동작 |
| `scripts/verify.sh` 검사 추가 | 강 | 결과물로 판정 가능한 것 |
| 회귀 테스트 | 최강 | 코드로 재현 가능한 버그 |

원칙: **CLAUDE.md에 규칙을 늘리는 것은 최후의 수단이다.** 스크립트로 막을 수 있으면 스크립트로 막아라.

## 3) 실제로 파일을 수정하라
- CLAUDE.md의 "금지 규칙" 섹션에 추가 (한 줄, 명령형, 이유를 괄호로)
- verify.sh에 검사 step 추가
- 중복·모순되는 기존 규칙이 있으면 **삭제하거나 통합**하라

## 4) 하네스 다이어트 (매번 수행)
- CLAUDE.md가 **60줄**을 넘으면 경고하고, 가장 값이 낮은 규칙 후보를 제시하라.
- 규칙이 서로 충돌하면 지적하라. 비대해진 하네스는 없는 것보다 나쁘다.

## 출력
```
승격한 규칙 N개:
1. [수단] 내용 — 대응하는 실패:
...
삭제/통합한 규칙:
CLAUDE.md 현재 줄 수: N (권장 60 이하)
```
