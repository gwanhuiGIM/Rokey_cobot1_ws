# 실기 투입 전 안전 점검: $ARGUMENTS

너는 이 점검을 통과시키는 것이 목적이 아니라 **위험을 찾아내는 것**이 목적이다.
하나라도 불확실하면 "통과"라고 쓰지 말고 사람 확인을 요청하라.

## A. 코드 정적 점검
- [ ] 속도/가속도 파라미터의 **상한**이 코드에 명시되어 있는가? 기본값이 안전한 값인가?
- [ ] 목표 자세(joint/pose)에 **범위 검사**가 있는가? 검사 실패 시 명령을 보내지 않고 거부하는가?
- [ ] 힘/토크 임계값(`get_external_torque` 등) 초과 시 **즉시 정지** 경로가 있는가?
- [ ] 예외 발생 시 로봇이 마지막 명령을 계속 수행하지 않고 정지하는가? (`try/finally`에 stop 호출)
- [ ] 워치독/타임아웃이 있는가? 상위 노드가 죽으면 로봇이 멈추는가?
- [ ] 단위 혼동 없는가? (mm vs m, deg vs rad) 변환 지점을 모두 나열하라.
- [ ] 좌표계: 베이스/툴/카메라/워크 프레임을 혼동하지 않았는가? TF 체인을 적어라.

## B. 런타임 사전 확인 (읽기 전용 명령만 실행)
```bash
ros2 node list | grep -i dsr        # 컨트롤러 노드 생존 확인
ros2 service list -t | grep -i dsr  # 서비스 서버 존재 확인
ros2 param get <node> <속도 파라미터>
ros2 topic echo /dsr01/joint_states --once
```
- [ ] 컨트롤러 노드가 실제로 살아 있는가? (없으면 `set_tool()` 등에서 무한 대기한다)
- [ ] 현재 관절값이 예상 시작 자세와 일치하는가?

## C. 물리 환경 (사람이 눈으로 확인 — 나에게 질문하라)
- [ ] E-stop이 손 닿는 위치에 있는가?
- [ ] 작업 반경 내 사람/장애물 없는가?
- [ ] 그리퍼에 물체가 잡혀 있는가? 낙하 시 위험한가?
- [ ] 첫 실행은 **저속(예: 정격의 10~20%)**으로 설정되어 있는가?

## 출력
```
안전 게이트 결과: 통과 / 조건부 통과 / 차단
- 차단 사유:
- 사람이 직접 확인해야 할 항목:
- 권장 첫 실행 파라미터 (속도/가속도):
```
**너는 실기 모션 명령을 직접 실행하지 않는다.** 실행은 사람이 한다.
