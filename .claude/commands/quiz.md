# 코드베이스 퀴즈

## 대상
- 최근 변경: !`git diff --stat HEAD~5 HEAD`
- 지정: $ARGUMENTS

## 목적
에이전트가 쓴 코드 중 **사용자가 설명하지 못하는 부분**을 찾아낸다. 설명 못 하는 코드는 유지보수 부채이고,
장애가 났을 때 사용자를 무력하게 만든다.

## 문제 출제 (5문제, 난이도 오름차순)
아래 유형에서 고른다. **정답을 미리 보여주지 마라.**

1. **동작 추적**: "이 노드에 X 토픽이 20Hz로 들어오면 내부에서 무슨 일이 순서대로 일어나나?"
2. **왜 이 선택인가**: "여기서 A 대신 B를 쓴 이유는? 뭘 포기한 건가?"
3. **깨뜨리기**: "이 코드를 한 줄 고쳐서 조용히 오작동하게 만들려면 어디를 건드리겠나?"
4. **실패 모드**: "센서가 3초간 멈추면 이 시스템은 어떻게 되나?"
5. **처음부터**: "이 함수를 지금 백지에서 다시 쓴다면 첫 세 줄은?"

## 채점
사용자가 답한 뒤에만 정답을 공개한다. 각 문항에 대해:
```
판정: 정확 / 부분적 / 오해 있음
핵심 격차:
읽어야 할 곳: <파일:라인 또는 문서>
```

마지막에 종합:
```
설명 가능한 영역:
블랙박스 영역 (위험):  ← 여기가 다음에 직접 손으로 만들어봐야 할 곳
권장 학습 1가지:
```
`docs/growth-log.md`에 결과를 누적하라.
