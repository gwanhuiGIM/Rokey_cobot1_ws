# 세션 상태 저장

컨텍스트는 사라지지만 파일은 남는다. `docs/state.md`를 아래 형식으로 **덮어쓰기** 하라.

```markdown
# 현재 상태 (<날짜 시각>)

## 지금 하고 있는 것
<1~2줄. 다음 세션의 첫 문장이 될 내용>

## 마지막 커밋
<해시 + 메시지>

## 미커밋 변경
<git status --short 결과와, 각 파일이 어떤 상태인지 (작업중/실험/버려도 됨)>

## 다음에 할 일 (우선순위 순)
1.
2.

## 막혀 있는 것
| 문제 | 지금까지 시도한 것 | 다음에 시도할 것 |
|---|---|---|

## 절대 잊으면 안 되는 것
- <예: dsr01 컨트롤러가 안 떠 있으면 set_tool()이 무한 대기함>

## 현재 하드웨어/환경 상태
- 로봇 자세, 그리퍼 상태, 실행 중인 노드, 켜져 있는 장비
```

작성 후 요약 3줄만 채팅에 출력하고 끝낸다.
