# 현실 제약 대장
> 코드를 봐서는 알 수 없는 것들. 에이전트가 이 파일과 모순되는 제안을 하면 그건 오답이다.
> 대화 중 새 제약이 드러나면 `/dump`로 즉시 추가한다.

## 하드웨어
| 제약 | 구체 내용 | 발견 경위 | 날짜 |
|---|---|---|---|
| 예: 그리퍼 개체차 | RG2-FT 힘 센서 영점이 매 전원 인가 시 ±0.3N 흔들림 | 실기 반복 테스트 | |

## 환경·현장
| 제약 | 구체 내용 | 발견 경위 | 날짜 |
|---|---|---|---|
| 예: 조명 | 오후 3시 이후 창측 반사로 HSV 임계값 무효 | 현장 관찰 | |

## 이미 시도했다가 버린 접근 (가장 중요 — 에이전트가 자꾸 다시 제안한다)
| 접근 | 왜 버렸나 | 다시 검토할 조건 |
|---|---|---|
